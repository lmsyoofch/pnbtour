# PuinoonBint World Tour

Complete static website, exported 19 November 2026.
Includes the separate Tour, Their footsteps and Giveaway views, the unobstructed Macau photograph, 17 credited place photographs and the watermarked passport cover.

## Upload to GitHub

1. Extract this ZIP first.
2. Create or open your GitHub repository.
3. Upload all extracted files and the entire places folder. Keep index.html at the repository root, not inside an extra folder.
4. Commit the files.

Do not upload only the ZIP. GitHub needs its extracted contents.

## Hosting

This is a static HTML, CSS and JavaScript site. It requires no installation, build command, API key or backend.

For GitHub Pages, publish the main branch and root folder through the repository Pages settings. The included .nojekyll file supports plain static hosting.

For Vercel, import this GitHub repository as a static project (Other). No build command is needed. Serve the repository root.

## Files to edit

- index.html: page content, navigation and giveaway conditions.
- style.css: layout, colours and mobile styling.
- app.js: tour cities, event details, visited places, filtering and tab navigation.
- photos.js: photo file references, attribution and licence links.
- macau.jpg: PuinoonBint Macau photograph.
- passport-cover-watermarked.jpeg: current giveaway image.
- places/: all place photographs.

Keep photo attribution and licence links intact. The giveaway conditions remain to be announced. Event information is a snapshot and should be checked against official announcements before updates or travel.

The ChatGPT Sites hosting configuration and Git credentials are intentionally excluded. This package runs independently of ChatGPT Sites.
